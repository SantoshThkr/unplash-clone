# GitHub Profile Viewer

A simple React application that displays public GitHub profile and repository information.

## Features

- Search GitHub users
- View profile information
- View repositories
- Repository details
- Loading state
- Error handling
- Responsive UI

## Tech Stack

- React
- JavaScript
- Axios
- CSS
- GitHub REST API
- Jest
- React Testing Library

## Installation

```
npm install
```

## Run

```
npm start
```

## Test

```
npm test
```

## API

Uses the public [GitHub REST API](https://docs.github.com/en/rest). No token is needed, but unauthenticated requests are limited to 60 per hour.
